# Surprisal Labs

**Infrastructure for open-ended discovery.**

Most tools answer questions you already have. We build systems that go looking for the ones you don't.
Surprisal Labs develops infrastructure for open-ended search over data: models that propose ideas, test them, and keep exploring past the first good answer. The goal is to make discovery something an organization can run continuously, not something that only happens by accident.
